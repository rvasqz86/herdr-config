# hq team Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `hq team` — a manager-driven multi-agent pipeline (spec → spec review → per-task implement / runtime check / review → final pass) with two human gates, running inside herdr.

**Architecture:** `bin/hq` (bash) only builds the herdr layout, starts agents with the right flags and sends each its first prompt; it also offers `hq respawn` for fresh crew sessions. All orchestration logic lives in `roles/manager.md`, which the manager (claude) follows, driving crew agents through the `herdr` CLI. Crew behaviour lives in four more role files. All pipeline state is files under the target repo's `.hq/`.

**Tech Stack:** bash 5, jq, herdr 0.9 CLI, git, claude / omp / copilot / cursor-agent. Tests are plain bash scripts with a fake `herdr` on `PATH`.

**Spec:** `~/.config/herdr/docs/specs/2026-09-23-hq-team-design.md`

## Global Constraints

- Agent names are `<label>-<role>`, roles exactly: `manager`, `planner`, `specrev`, `impl`, `taskrev`; names must match `[a-z][a-z0-9_-]{0,31}`.
- Tools: manager=claude, planner=omp, specrev=copilot, impl=cursor, taskrev=claude.
- Crew reply contract: exactly `DONE <path>` or `BLOCKED: <reason>`.
- Crew never commits. Manager commits once per task: `task NN: <title>`.
- Max 2 spec-review rounds; max 3 FIX rounds per task.
- Timeouts: spec 20m, impl 30m, reviews 10m.
- Branch `hq/<slug>`; refuse to start on a dirty working tree.
- `autonomy=trusted` flags apply only on `hq/*` branches and never to the manager: claude `--dangerously-skip-permissions`, omp `--auto-approve`, copilot `--allow-all-tools`, cursor `--force --trust`.
- Manager never answers another agent's approval prompt; never kills processes it didn't start.
- Gate 2 `ship` default = `gh pr create`.
- Runtime log size: `log_max` in `.hq/runtime`, default `20M`; `hq runlog` rotates `.hq/runtime.log` → `.hq/runtime.log.1` at half of it, so the two together stay about `log_max`.

Three small refinements over the spec (all within its intent):
- The runtime pane runs the dev server through `hq runlog .hq/runtime.log <log_max>` (a rotating tee, cleared per restart), so the runtime check greps files instead of scraping scrollback; `.hq/.gitignore` excludes `runtime.log*`.
- The implementer may also append an `## Implementation notes` section to its task file, for the reviewer.
- The test fixture uses plain `node:http` instead of Express (no `npm install` needed).

## Review Focus

1. A brief containing quotes, `$(...)`, backticks or newlines must reach the manager verbatim and never execute — pinned in Task 2.
2. A repo path containing spaces must work for every `--cwd` — pinned in Task 2.
3. Labels that slug badly (`2025_Taxes`, `2025`, 40-char names) must still yield valid, unique agent names — pinned in Task 1.
4. Launching a second team with the same label while the first is live must fail fast with a clear message, not half-build a layout — pinned in Task 2.
5. `autonomy=trusted` on a non-`hq/*` branch must start agents without auto-approve flags; `respawn` must never kill the pane's shell — pinned in Tasks 1 and 3.

```bash
role_file() {
  case $1 in
    manager) echo "$ROLES_DIR/manager.md" ;;
    planner) echo "$ROLES_DIR/planner.md" ;;
    specrev) echo "$ROLES_DIR/spec-review.md" ;;

runtime_get() { # dir key -> value, empty if unset
  local f="$1/.hq/runtime"
  [ -f "$f" ] || return 0
  sed -n "s/^$2=//p" "$f" | sed 's/[[:space:]]*#.*$//; s/[[:space:]]*$//' | tail -n 1
}

current_branch() { git -C "$1" symbolic-ref --short -q HEAD || true; }

agent_flags() { # kind autonomy branch -> one flag per line
  [ "$2" = trusted ] && [[ $3 == hq/* ]] || return 0
  case $1 in
    claude) echo --dangerously-skip-permissions ;;
    omp) echo --auto-approve ;;
    copilot) echo --allow-all-tools ;;
    cursor) printf '%s\n' --force --trust ;;
  esac
}

size_bytes() { # 20M | 512K | 1G | 1000 | '' (default 20M) -> bytes
  local v=${1:-20M} n
  [[ $v =~ ^([0-9]+)([KkMmGg]?)$ ]] || return 1
  n=${BASH_REMATCH[1]}
  case ${BASH_REMATCH[2]} in
    [Kk]) n=$((n * 1024)) ;;
    [Mm]) n=$((n * 1024 * 1024)) ;;
    [Gg]) n=$((n * 1024 * 1024 * 1024)) ;;
  esac
  echo "$n"
}
```

```bash
# Start an agent; don't abort the layout if it hits a trust/login prompt.
start_agent() { # name kind pane [agent-args...]
  local name=$1 kind=$2 pane=$3 extra=()
  shift 3
  [ $# -gt 0 ] && extra=(-- "$@")
  if ! herdr agent start "$name" --kind "$kind" --pane "$pane" --timeout 60000 "${extra[@]}" >/dev/null 2>&1; then
    echo "hq: $name ($kind) needs attention in its pane (trust prompt / login?)" >&2
  fi
}
```
Add after `new_tab`:
```bash
start_role() { # label role pane dir
  local kind flags=()
  kind=$(role_kind "$2")
  if [ "$2" != manager ]; then
    mapfile -t flags < <(agent_flags "$kind" "$(runtime_get "$4" autonomy)" "$(current_branch "$4")")
  fi
  start_agent "$1-$2" "$kind" "$3" "${flags[@]}"
}

prompt_agent() { # name text
  herdr agent prompt "$1" "$2" --wait --timeout 180000 >/dev/null 2>&1 ||
    echo "hq: $1 did not confirm its role prompt; check its pane" >&2
}

team_prompt_crew() { # role dir
  printf 'Your role file is %s. Read it now and follow it for this whole session. Project root: %s. Do nothing else until the manager sends you a task. Reply READY.' \
    "$(role_file "$1")" "$2"
}

team_prompt_manager() { # dir label runtime_pane mode brief
  cat <<EOF
Your role file is $(role_file manager). Read it now and follow it for this whole session.
Project root: $1
Team label: $2
Crew agents: $2-planner (omp), $2-specrev (copilot), $2-impl (cursor), $2-taskrev (claude)
Runtime pane: $3
Mode: $4
Brief:
$5
EOF
}

team_names_free() { # label
  local taken
  taken=$(herdr agent list | jq -r --arg p "$1-" '.result.agents[]? | .name // empty | select(startswith($p))')
  [ -z "$taken" ] || die "agents already running for '$1': $(tr '\n' ' ' <<<"$taken")— close that workspace or pick another label"
}

layout_team() { # dir label mode brief
  local dir=$1 label=$2 mode=$3 brief=$4 name ws root tab crew runtime specrev impl taskrev role
  name=$(slug "$label")
  team_names_free "$name"
  read -r ws root tab < <(new_workspace "$dir" "$label")
  herdr tab rename "$tab" manager >/dev/null
  split "$root" right "$dir" >/dev/null   # your shell
  crew=$(new_tab "$ws" "$dir" crew)
  runtime=$(herdr pane split "$crew" --direction down --ratio 0.75 --cwd "$dir" --no-focus | jq -r '.result.pane.pane_id')
  herdr pane rename "$runtime" runtime >/dev/null
  specrev=$(split "$crew" right "$dir")
  impl=$(split "$crew" down "$dir")
  taskrev=$(split "$specrev" down "$dir")
  local -A pane=([planner]=$crew [specrev]=$specrev [impl]=$impl [taskrev]=$taskrev)
  start_role "$name" manager "$root" "$dir"
  for role in planner specrev impl taskrev; do
    start_role "$name" "$role" "${pane[$role]}" "$dir"
    prompt_agent "$name-$role" "$(team_prompt_crew "$role" "$dir")"
  done
  # No --wait: the manager's first turn is the whole pipeline.
  herdr agent prompt "$name-manager" "$(team_prompt_manager "$dir" "$name" "$runtime" "$mode" "$brief")" >/dev/null
  herdr workspace focus "$ws" >/dev/null
}

cmd_team() {
  local usage='usage: hq team <dir> "<brief>" [label] | hq team --resume <dir> [label]'
  local resume=0 dir
  if [ "${1:-}" = --resume ]; then resume=1; shift; fi
  dir=$(realpath -e "${1:-}" 2>/dev/null) || die "$usage"
  git -C "$dir" rev-parse --git-dir >/dev/null 2>&1 || die "$dir is not a git repository"
  if [ $resume = 1 ]; then
    [ -f "$dir/.hq/state" ] || die "nothing to resume: $dir/.hq/state not found"
    layout_team "$dir" "${2:-$(basename "$dir")}" resume "(resuming — read .hq/brief.md and .hq/state)"
  else
    [ -n "${2:-}" ] || die "$usage"
    layout_team "$dir" "${3:-$(basename "$dir")}" new "$2"
  fi
}
```

```bash
shell_idle() { # pane -> 0 when the shell itself is in the foreground
  herdr pane process-info --pane "$1" |
    jq -e '.result.process_info | .foreground_process_group_id == .shell_pid' >/dev/null

cmd_respawn() { # <label>-<role>
  local name=${1:-} role label info pane dir pgid i
  [ -n "$name" ] || die "usage: hq respawn <label>-<role>"
  role=${name##*-}; label=${name%-*}
  [ "$role" != manager ] || die "respawn is for crew agents, not the manager"
  role_kind "$role" >/dev/null || die "unknown role in '$name' (expected planner|specrev|impl|taskrev)"
  info=$(herdr agent get "$name") || die "no live agent named $name"
  pane=$(jq -r '.result.agent.pane_id' <<<"$info")
  dir=$(jq -r '.result.agent.cwd' <<<"$info")
  if ! shell_idle "$pane"; then
    # Never signal the shell's own group — only the agent in the foreground.
    pgid=$(herdr pane process-info --pane "$pane" | jq -r '.result.process_info | select(.foreground_process_group_id != .shell_pid) | .foreground_process_group_id')
    [ -n "$pgid" ] && kill -TERM -- "-$pgid" 2>/dev/null
    for i in $(seq 1 20); do
      shell_idle "$pane" && break
      [ "$i" = 10 ] && [ -n "$pgid" ] && kill -KILL -- "-$pgid" 2>/dev/null
      sleep 0.5
    done
    shell_idle "$pane" || die "$name did not exit (pane $pane)"
  fi
  start_role "$label" "$role" "$pane" "$dir"
  prompt_agent "$name" "$(team_prompt_crew "$role" "$dir")"
}
```

```bash
cmd_runlog() { # <path> [max] — tee that keeps <path> + <path>.1, together about <max>
  local path=${1:-} max
  [ -n "$path" ] || die "usage: <cmd> 2>&1 | hq runlog <path> [max]"
  max=$(size_bytes "${2:-}") || die "bad size '${2:-}' (use e.g. 20M, 512K)"
  : >"$path"
  rm -f "$path.1"
  LC_ALL=C awk -v path="$path" -v half=$((max / 2)) '
    {
      print; fflush()
      print >> path; fflush(path)
      bytes += length($0) + 1
      if (bytes >= half) {
        close(path)
        system("mv -f \"" path "\" \"" path ".1\" && : > \"" path "\"")
        bytes = 0
      }
    }'
}
```

````markdown
You run a feature from brief to reviewed branch. You drive a crew of agents through the `herdr` CLI, judge every handoff against the architecture, and keep the result coherent. You stop for the human at exactly two gates.

## Phase A — Setup

1. `hq respawn L-impl`, then prompt: `"Implement .hq/tasks/NN-*.md, round R.<if R>1: Fix every finding in the latest round of .hq/reviews/NN.md.> When finished reply exactly DONE <path> or BLOCKED: <reason>."` with timeout 1800000.

4. Run the `test` command yourself in your own shell. Failures → runtime finding.
5. `grep -EnC3 "<errors>" .hq/runtime.log.1 .hq/runtime.log 2>/dev/null` → each match is a runtime finding; copy only these matches (with their 3 lines of context) into the review, never the whole log. 1. Review the whole branch: `git diff <base>...HEAD` against `.hq/architecture.md` and `.hq/spec.md`. Look for inconsistency across tasks, leftover TODOs, dead code, missing tests.
````
